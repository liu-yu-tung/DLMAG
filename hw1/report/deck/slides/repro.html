Reproducibility

  • Release: code, README and pinned requirements.txt (Python 3.12, torch 2.14.0+cu130, transformers 5.17.0); checkpoints with SHA-256 (links on page 1).
  • Check: a fresh venv built only from requirements.txt, run from audio, gives the same top-3 lists (order included) as the training-time features on 234/234 test clips, in both modes. A repeated run is byte-identical.
  • Runtime (RTX 4060 Ti 16 GB, 234 test clips): 7 min 3 s default, 1 min 46 s with --no-alm. Seeds 0, 1, 2; settings fixed before training.

Bug 1, found and fixed

MERT-v2's rotary frequencies are a non-persistent buffer. Loaded on the meta device by transformers 5, they were left uninitialized, so features changed between loads (25–55%). Fix: restore the buffer after loading.

Bug 2, found and fixed

At inference the fine-tuned blocks reused a rotary table built in fp32; training built it under bf16 autocast. Log-probs moved by up to 0.81. Fix: clear the cache, so inference matches training exactly.
